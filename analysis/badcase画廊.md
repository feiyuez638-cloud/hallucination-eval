# Badcase 画廊：按幻觉类型与实验版本

> 本文件由 `python analysis/badcase_gallery.py` 从 `eval/runs/` 里已有的作答与裁判判定生成，**请勿手改**；`python scripts/check_site_numbers.py` 会重新生成一份并逐字比对。标签是本地 LLM 裁判的代理判定（口径同报告 §2：「答对」= 作答且未判幻觉）。
> 选例方法：每类先用规则圈出候选池（版本对 × 判定转移，池大小见各条标题），再人工挑代表性样本。

## 1. 长回答夹带编造（p0 → V1 提示约束 + 限长）

p0 几乎不拒答、回答长，错误多出在正确核心旁边的附加细节里。V1 让模型答短、没把握就说不知道，这类幻觉随之消失，但一部分本来答对的题也一起变成了拒答（最后一条）。

### 1.1 sqa-0406（SimpleQA；p0 幻觉 → V1 答对；同类候选 27 题）

- **问题**：美国国会图书馆控制号的英文缩写是什么？
- **参考答案**：LCCN

| | p0 原样作答 | V1 系统提示约束 |
|---|---|---|
| 判定 | 幻觉 | 答对 |
| 回答 | 美国国会图书馆控制号的英文缩写是 LC Control No.，通常简写为 LC。 具体解释如下： - “Library of Congress” 是美国国会图书馆的全称。 - “Control Number” 是其为馆藏书籍和资料分配的唯一标识号码，用于图书分类和管理。 - 这个号码通常以“LC”开头，例如：LC: 2023045678。 因此，美国国会图……（全文 204 字） | 美国国会图书馆控制号的英文缩写是LCCN。 |
| 裁判理由 | 回答声称缩写是"LC"，但参考材料明确给出的标准答案是LCCN，两者冲突。 | 回答与参考材料中的标准答案一致，无幻觉且未拒答。 |

**成因**：长回答里先给了一个似是而非的缩写（LC Control No.），限长后只剩核心答案，反而答对；属于「说多错多」。

## 2. 参数知识缺失：编造一个「看着合理」的实体（V2 → V3 检索）

V2 放宽拒答后，4B 对没把握的长尾事实倾向于给出一个高频、相关的错实体。补上维基检索后，标准答案进了前 5 段的题大多直接答对；检索没把答案送进前 5 段时，错误照旧，直到 V4 重排把它捞回来（最后一条）。

## 3. 检索之后仍然错：资料带偏、同名实体与推理矛盾（V3 → V4）

V4 的知识题幻觉里，错误往往不是「没有资料」，而是资料把模型带到了错的实体上，或者模型拿着对的事实推出错的结论。

- **参考答案**：是吴道子作画。吴道子作画、张旭草书、裴旻舞剑在当时被人称作“三绝”。吴道子为阳翟（今河南禹州市）人。中国唐代著名画家，被称为“百代画圣”。

|---|---|---|
| 判定 | 幻觉 | 幻觉 |
| 回答 | 与张旭草书、裴旻舞剑共称为“三绝”的是李白的诗歌。 | 李白的诗歌。 |
| 裁判理由 | 回答声称'三绝'是李白的诗歌，但参考材料明确指出是吴道子作画，两者冲突 | 回答声称是李白的诗歌，与参考材料中明确指出为吴道子作画相冲突。 |

<a id="4-premise"></a>
## 4. 顺着错误前提答（Misleading，V3 → V4）

误导题缺的不是知识，而是识别前提有问题的能力。资料一多，模型更容易在资料里找一个「答案」去满足题目的前提（推测，没有单独验证）。下面三题都是 V3 不幻觉、V4 幻觉；同期也有题反方向变好，净变化在噪声内（报告 §4.2）。

### 4.1 hqa-31（Misleading；V3 答对 → V4 幻觉；同类候选 15 题）

- **问题**：所有中国人在元宵节这一天都会吃什么食物？
- **参考答案**：这个问题无法回答，元宵节吃元宵或汤圆虽然是习俗，但并不代表每个人都会遵守习俗。

| | V3 + BM25 检索 | V4 + bge 重排 |
|---|---|---|
| 判定 | 答对 | 幻觉 |
| 回答 | 所有中国人在元宵节这一天不会都会吃什么食物。 | 所有中国人在元宵节这一天都会吃元宵或汤圆。 |
| 裁判理由 | 回答与参考材料一致，指出并非所有中国人都会在元宵节吃同一种食物，但表述略显别扭 | 回答声称所有中国人都吃元宵或汤圆，与参考材料中'每个人吃的东西可能各不相同'矛盾 |

**成因**：检索回来 4 段元宵节词条，模型接受了「所有中国人」的以偏概全前提，把习俗当成全称事实；V3 那句被判答对的回答本身语句不通。

## 7. 泛化「先挑错」传染到正常题（V4 → V5）

V5 让模型先检查问题有没有错，但没有限定适用范围。新增的幻觉主要在正常的知识题上：模型开始否认真实前提，或用一个「正确说法」顶替原本的「我不知道」。
