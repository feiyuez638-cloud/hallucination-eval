- 唯一考核指标：幻觉率 HR = N_hal / N_all × 100%。N_hal = 输出存在事实错误或信息捏造的样本数；N_all = 全部**有效**测试样本数。越低越好。
- 形式：用主办方指定模型，微调或其他自研技术，在**限定时间内**回应主办方给出的幻觉测试题。

- 风险点：公式里没有「拒答」项，若拒答不算幻觉，全拒答会得 0% —— 主办方大概率用「有效样本」或正常题比例堵这个口子，方案不能押在拒答上。
