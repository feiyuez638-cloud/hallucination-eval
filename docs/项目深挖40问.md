# 项目深挖 40 问

> 面试官顺着项目往下挖时最可能问的问题，共 40 问，分六组：方法与指标、统计、裁判、数据、局限、如果重做。每题只给**答题要点**，现场用自己的话串起来。
>
> - 答案里的每个数字都能在 [report/大模型幻觉评测报告.md](../report/大模型幻觉评测报告.md) 里找到，`python scripts/check_site_numbers.py` 会逐个核对；括号里的 § 是报告章节，方便现场翻原文。
> - 口径：本地 LLM 裁判的代理指标，单裁判、单次采样、开发集；「答对」= 作答且未判幻觉。
> - 和 [面试准备.md](面试准备.md) 的分工：那份是高频问题的完整参考回答，这份是更深一层的追问清单。具体错例见 [badcase 画廊](../analysis/badcase画廊.md)。
> - 答不上来就说「这个我没测，我会这样测……」，不现编数字。

## A. 方法与指标

**Q1. 你怎么定义「幻觉」？裁判具体输出什么？**（§2）
- 裁判只看问题、参考材料、回答，输出两个布尔值：`hallucinated`（与参考材料冲突，或声称某来源写了材料显示没写的内容）、`refused`（明确表示无法回答、不确定或材料不足）。
- 两个可以同时为真：拒答的同时编了理由，叫「双标签」，V5 有 34 道。
- 裁判被要求只依据材料、不用自身记忆，避免拿它自己的错误知识来判。

**Q2. 为什么非要三个数一起报？只报一个幻觉率不行吗？**（§2、§4.2）
- 「拒答算有效」口径奖励过度拒答：V1 幻觉率 19.4%，但拒答率 65.7%。
- 「拒答剔除」口径有选择效应：V1 是 53.2%，比 p0 的 72.2% 低，可作答的题从 436 道缩到 154 道，没把握的题被拒掉了，剩下的自然更准。
- 两个比例都能被拒答操纵，所以加一个绝对数「答对」：V1 答对 121 → 72，一眼看出不是进步。

**Q3. 「答对」真的是答对吗？**（§2、§3.4）
- 不是。裁判不单独判正误，「答对」只是「作答且未判幻觉」。答非所问、只答一半也会落在这里，比如 hqa-31 的 V3 回答语句不通照样判「答对」。
- SimpleQA 上做过独立核对：V4 里「规则未匹配、裁判判答对」随机抽 15 条，13 条确实答对，2 条存疑。大体接近，但不等于。
- 重做会让裁判单独输出「是否完整回答」，或者干脆改名叫「非幻觉作答」。

**Q4. 你说每版只改一处，真的做到了吗？**（表 1）
- 没完全做到：V1 同时改了系统提示和 max_tokens 200，两处一起改，所以分不清幻觉下降有多少来自「答短」、多少来自「不确定就说不知道」。
- V3 加检索时系统提示也同步加了一条资料用法，严格说也是两处，但那条是检索能用起来的必要说明。
- 主动说出来比被问出来好；重做时 V1 应拆成两版。

**Q5. 「事先定的判据」长什么样？为什么要事先定？**（§4.2）
- V5：幻觉 < 83 且 SimpleQA HR ≤ 11.0%（结果 151 和 26.8%，两条都没过）。
- V6：SimpleQA 触发 ≤ 9/300，且拦住幻觉 > 0、误拒答对 = 0（结果触发 73/300、误拒 67）。
- 事先定是为了不在开发集上「调到它过」：没过就停，否则留出集就失去意义，也容易事后挑显著结果骗自己。

**Q6. V6 / V7 为什么是离线回放？回放结果可信吗？**（表 1 注、§4.2）
- 两者都没过事先定的门槛，没有进入作答阶段；回放假设「触发的题改答我不知道（记为拒答、非幻觉），其余保留 V4 判定」。
- 这个假设偏乐观：真跑时模型未必乖乖说不知道，回放给出的是拦截的**上限**收益。即便如此，V6 也要误拒 67 道答对题才拦住 19 个幻觉。
- V6 回放后幻觉率 14.3% 是表里最低，但那是多拒答 83 题换来的，不代表最好。

**Q7. 检索为什么有效？证据是因果还是相关？**（§4.2、§6）
- V2 → V3 配对：幻觉 206 → 83、答对 138 → 249，均 p<0.001；V2 幻觉题里 110 题变答对。
- 机制：SimpleQA 多是长尾事实，4B 参数里没有，补上证据就能答。前 5 段命中的 205 题答对 85.4%，没命中的 95 题只答对 35.8%。
- 这是相关不是严格因果：没命中的题本身往往也更冷门。

**Q8. V5「先查问题有没有错」为什么反而更差？**（§4.2、§5.4）
- 指令没限定适用范围，传染到了正常题：SimpleQA 只 V4 幻觉 6、只 V5 幻觉 56（p<0.001），Knowledge 3 / 15（p=0.008），Misleading 4 / 9 反而不显著。
- 还有 56 题是 V4 拒答、V5 改成了编造：模型用一个「正确说法」顶替「我不知道」。
- 典型例子 sqa-0062：本来答对「陶侃」，V5 说「问题本身有误」并编出西晋。教训：小模型会把「挑错」当成一种回答风格，而不是一种判断。

## B. 统计

**Q9. 为什么用 McNemar 配对检验，而不是比较两个比例？**（§2、§4.2）
- 两版答的是同一批题，是配对样本；直接比比例会把「题目本身难不难」的方差算进来，检验力低。
- McNemar 只看不一致的题。V3 → V4 总幻觉率 18.4% 对 18.5% 看着一样，配对一看是只 V3 幻觉 38、只 V4 幻觉 38，两版并非答得一样，只是正好抵消。

**Q10. 为什么用精确 McNemar（二项检验）而不是卡方近似？**（§2、§4.3）
- 有些对比的不一致对很少，比如 V8 在 Misleading 上只 V4 幻觉 10、只 V8 幻觉 0，卡方近似在小计数下不可靠；精确版本直接按二项分布算，p=0.002。

**Q11. 置信区间用的什么方法？它覆盖了哪些误差？**（§2）
- Wilson 95% 区间，比正态近似在小样本和极端比例下更稳，例如 V4 18.5% [15.2, 22.4]。
- 它只反映「抽到哪些题」的误差，**不含**裁判误判和作答采样的随机性，所以真实不确定性比区间更大。

**Q12. 你做了很多检验，多重比较怎么处理？哪些结论站得住？**（§7）
- 7 组配对 × 幻觉 / 答对 = 14 个 McNemar 检验，没有事先指定主假设，外审时补做 Holm 校正。
- 校正后仍 p<0.001：p0→V1、V1→V2、V2→V3、V4→V5、b0→V4-8B。
- 不再显著：V3→V4 的答对增加（0.018 → 0.092）、V4-8B→V8-8B 的幻觉减少（0.036 → 0.143），表述降级为「倾向」。

**Q13. 450 题够不够？分题型呢？**（§7）
- 总体 HR 的 95% 区间半宽约 3.6～4.6 个百分点，区分检索、V5 退步这类大改动够用。
- 分题型不够：Misleading-hard 只有 30 题，一题就是 3.3 个百分点，V4 的 50.0% 对应区间 [33.2, 66.8]。
- 正确做法：先定想检测多大的差异再反推题数；配对设计比独立样本省题。

**Q14. 为什么 V5 的「拒答剔除」HR 反而低于「拒答算有效」HR？**（§2）
- 「拒答剔除」把双标签题从分子分母一起去掉。V5 有 34 道双标签，去掉后分子减得多，所以 31.5% 低于 34.3%。
- 这也说明「拒答剔除」口径跨版本比较时分母不同，含选择效应，只能和另外两个数一起读。

**Q15. 做过哪些敏感性分析？结论稳不稳？**（§2、§3.4）
- 去掉宽松补解析的判定：各版 HR 最多变 1.5 个百分点（V4 18.5% → 17.0%）。
- 缺判定的题全按幻觉或全按不幻觉算：最多变 1.8 个百分点。
- 「资料未提及」伪影改记为拒答：V3 18.4% → 16.4%，V4 18.5% → 17.2%，V5 34.3% → 28.4%。
- 除了本来就持平的 V3 / V4 互有先后，都不改变版本排序和结论。

**Q16. 作答温度不为零、每题只答一次，会影响结论吗？**（§7）
- 4B 温度 0.7、8B 温度 0.6，每题只答一次，没有估计采样方差。
- McNemar 的配对设计在「两版本无差异」的原假设下仍然成立，但单题判定会随采样变化。
- 一个教训：V5 的 20 题小样已经是变差方向（幻觉 4 → 6），但 20 题上分不开噪声，没能据此提前叫停。

## C. 裁判

**Q17. 为什么用 LLM 裁判，不直接用规则匹配？**（§3.2、§3.4）
- 规则（标准答案是否为回答的子串）只适用于 SimpleQA 这种短答案；HalluQA 的参考答案是整句解释，误导题还要判「有没有顺着前提答」，规则做不了。
- 但规则可以当独立的粗代理去校验裁判，这正是交叉核对的用法（Q19）。

**Q18. 验收集 24 条全对，说明裁判准吗？**（§3.3、§3.4）
- 说明不了多少：24/24 的一致率 95% Wilson 下界只有 86.2%（23/23 是 85.7%），真实误判率高达 14% 也与结果相容。
- 领域也不同：验收集是规则文档类材料，开发集是开放域知识问答。

**Q19. 规则和裁判交叉核对的结果怎样？**（§3.4）
- 「规则命中中裁判判幻觉」：p0 54/133（40.6%），V4 只有 5/187（2.7%）；p0 高主要因为长回答在正确答案旁夹带了错误细节。
- V4「规则未匹配中裁判判答对」39/62：抽 15 条，13 条确实答对（写法不同，如「8」对「第八次」）。
- V4「规则命中、裁判判幻觉」5 条：2 条确有错误（sqa-0005、sqa-0583），3 条是裁判过严或标准答案有问题。
- 结论：SimpleQA 上大体可信，有双向噪声，每版估计有几到十几条误判。

**Q20. 你发现了裁判的哪些具体问题？**（§3.4）
- 判法不一致：sqa-0184 几乎一字不差的回答，V4 判答对，V5 判幻觉。
- 正确的补充信息被判幻觉：sqa-1079「集英社」、hqa-21 春节日期范围，理由都是「材料未提及」。
- 「资料未提及」伪影：模型指的是自己检索的段落，裁判当成「声称来源没写」；V5 有 32 条命中这种句式，其中 26 条被判幻觉。

**Q21. 跨裁判一致率 96.3%，κ 却只有 0.78，怎么解读？**（§3.4）
- κ 扣掉了偶然一致。这批 188 条里判幻觉的样本少（两个裁判分别 18 和 17 条），两方就算只按各自的比例随机判，也能有很高的一致率。
- 正例少，CI 很宽：[0.59, 0.91]，只够判断量级。`refused` 的 κ 是 0.97。
- 所以只报一致率会高估可靠性，κ 和一致率要一起报。

**Q22. 裁判 temperature 设成 0，为什么还会前后矛盾？对结论有什么影响？**（§3.4）
- agnes 同一输入判两次，423 对里 `hallucinated` 有 24 条矛盾，κ = 0.68 [0.55, 0.80]；gemini-flash 417 对 κ 0.99。agnes 带推理过程，温度 0 也不保证输出确定。
- 影响：V3→V4 幻觉不一致的 76 题里，有 13 题回答一字未改，只是裁判换了判法。这给「差几题的结论不可靠」提供了数据支撑。

**Q23. 4B 和 8B 的数字为什么不能横比？**（§3.2、§7）
- 两组裁判不同：4B 用 agnes-2.5-flash，8B 用 gemini-3.8-flash-high（前者额度失效后换的）。
- 所以 8B 的 SimpleQA HR 15.9% 高于 4B 的 10.0%，分不清是模型差异还是裁判差异。
- 188 条重叠上两个裁判判幻觉比例几乎相同（18 vs 17），但样本以 SimpleQA 短答案为主，gemini 又对「字面对上标准答案」稳定地更严，仍不足以排除裁判差异。

**Q24. 裁判输出解析失败怎么办？会不会引入偏差？**（§2）
- 先严格解析 JSON；失败的，从原文各找一次两个布尔值，恰好各出现一次才采用（宽松补解析，4B 每版 11～42 条，8B 为 0）；仍解析不出的不计入分母。
- 偏差用敏感性分析兜底：去掉补解析最多变 1.5 个百分点（Q15）。

## D. 数据

**Q25. 开发集是怎么构造的？为什么是这个配比？**（§3.1）
- `eval/make_dev.py` 固定种子（20261020）分层抽样：SimpleQA 300（6 个一级类各 50）、Knowledge 60、Misleading 60、Misleading-hard 30。
- 配比是为了让误导题够测、又不主导总分；代价是「全部」一栏是人为配比下的加权数，分题型数字更有意义（Q33）。

**Q26. 留出集为什么一直不用？打算怎么用？**（§3.1、§8）
- 其余 3000 题放进 `holdout_v1`，计划只在最后确认时用一次；本报告的实验都没用到它。
- 用法：上留出集前先写定唯一的主指标和主对比（如 V8 vs V4 的配对幻觉数），其余标为探索性，跑一次 V4 / V8。

**Q27. 检索的收益是不是被高估了？**（§7）
- 是。知识库是中文维基快照，SimpleQA 300 题里 258 题的出处本身含维基链接，答案大概率就在库里。
- 出处不含维基的 42 题，前 5 段命中率只有 42.9%（含维基的 72.5%）。
- V2 → V4 的 SimpleQA 答对率：含维基 38.1% → 79.0%，不含维基 14.3% → 42.9%。真实业务问题上收益应按偏低一档估计。

**Q28. 知识库和检索是怎么搭的？**（§4.2）
- 中文维基 2023-11 快照建 BM25 库：138 万篇、359 万段，繁转简、≤350 字切段、jieba 分词；把前 5 段放在问题前。
- V4 用 BAAI/bge-reranker-v2-m3 把 BM25 前 50 段重排后留前 5 段；检索 @1 54.0% → 64.0%、@5 68.3% → 72.7%。
- BM25 前 50 段里含答案的上限是 76.3%，再往上得靠召回端。

**Q29. HalluQA 的参考材料怎么给裁判？为什么不给错误答案样例？**（§3.2）
- 给数据集的正确回答 + 出处；不给错误回答样例，免得裁判照着样例的措辞去匹配。
- 代价是 HalluQA 的参考答案是整句解释，「算不算顺着前提答」本身更主观（Q35）。

**Q30. 数据本身有没有问题？**（§3.4）
- 有。抽查「规则命中、裁判判幻觉」时，3 条是裁判过严或标准答案本身有问题，例如 sqa-0083「2019 年 3 月」、sqa-0394 书名。
- 所以每版的判定里混有数据噪声和裁判噪声，差距小于约 10 题的结论都不可靠（这是按抽查粗估的经验线，不是统计推导）。

## E. 局限

**Q31. 这个项目最大的局限是什么？**（§1、§7）
- 所有数字都是单裁判、单次采样、开发集上的代理指标；HalluQA 上裁判没有独立核对；4B 和 8B 裁判不同。
- 直接后果：误导题和小差异的结论噪声最大，只能当方向线索。

**Q32. 哪些结论是「样本内」的？**（§7）
- V5、V7、V8 的设计参考了同一开发集上的错例，V4 也是在开发集上挑出来的最好版本，留出集一直没用，dev_v1 上的数字对这些版本偏乐观。
- 最典型的是 V8：Misleading HR 58.2% → 42.1%，但它点名的问法和从 dev_v1 误导题错例里归纳的类别是同一批。

**Q33. 总体幻觉率能代表真实场景吗？**（§7）
- 不能。开发集是 SimpleQA 300 + HalluQA 150 的分层抽样，「全部」一栏是这个人为配比下的加权数，不代表任何真实流量分布；换配比结论会变，分题型数字更有意义。

**Q34. 结论能推广到别的模型或领域吗？**（§7）
- 评测对象只是一个固定 prompt + 检索管线，没有微调；结论不外推到其他模型或其他领域。
- 能迁移的是方法：三个数一起报、事先写判据、配对检验、裁判验收与一致性。

**Q35. 为什么说误导题的结论比 SimpleQA 噪声更大？**（§3.4）
- 规则交叉核对只覆盖 SimpleQA，HalluQA 上没有独立核对。
- 给 V4 误导题 37 个幻觉人工归类时，8 个属于「裁判嫌多说少说」，约五分之一可能是裁判口径问题。
- 重叠样本里误导题也很少，跨裁判一致性基本没测到。

## F. 如果重做

**Q36. 如果重做，第一件事改什么？**（§8）
- 先写定唯一的主指标和主对比，其余标为探索性，再碰数据；这样 14 个检验的多重比较问题从源头就小了。
- 然后在留出集上只跑一次 V4 / V8 确认，而不是一直在 dev_v1 上迭代。

**Q37. 裁判怎么改？**（§3.4、§8）
- 把检索到的原始段落也交给裁判，消除「资料未提及」伪影。
- 把 rubric 边界和正反例写进裁判提示词（材料外细节、复述题干、译名、「我不知道」），用已发现的 34 条不一致样本做回归。
- 从两个基线版本抽 300 条两人独立标注：先算标注员之间的 κ，再报告裁判与人工金标准的 κ；同一批答案用两个裁判各判一次，解决 4B / 8B 不可比。

**Q38. 实验设计怎么改？**（§7、§8）
- 真正每版只改一处（V1 拆成「改提示」和「限长」两版）。
- 关键版本每题采样 3 次（或温度 0），报告均值与方差，再决定 V3 / V4 这类小差异。
