# 中文大模型幻觉评测：Qwen3-4B / 8B 的提示约束、检索与拦截

**一句话**：自建 450 题中文开发集，用 LLM 裁判逐版评测 Qwen3-4B / 8B 在提示约束、维基检索、重排、拦截下的幻觉率；所有数字可一条命令重算，并用 SQL 独立复现。

**做了什么**

- **评测集**：Chinese SimpleQA 300 + HalluQA 150（Knowledge / Misleading / Misleading-hard）固定种子分层抽样；另留 3000 题留出集未用。
- **裁判**：LLM 只依据标准答案给「幻觉 / 拒答」两个标签；上线前用 24 条人工标注验收集验收。
- **指标与实验**：同时报两种幻觉率（HR）口径和答对数，防止靠拒答刷低幻觉率；每版只改一处、事先写判据，相邻版本做精确 McNemar 配对检验 + Holm 校正。

**主要结果**（Qwen3-4B，裁判 agnes-2.5-flash；本地 LLM 裁判代理指标，非官方成绩；V6 / V7 为离线回放）

| 版本 | 改动 | 幻觉 | 拒答 | 答对 | HR（拒答算有效） | HR（拒答剔除） |
|---|---|---|---|---|---|---|
| p0 | 原样作答 | 325 | 12 | 121 | 72.5% | 72.2% |
| V1 | 系统提示约束 | 87 | 295 | 72 | 19.4% | 53.2% |
| V3 | + 维基检索 | 83 | 126 | 250 | 18.4% | 22.8% |
| **V4** | **+ 重排（基线）** | **83** | **106** | **267** | **18.5%** | **21.9%** |
| V5 | 先挑错提示 | 151 | 68 | 255 | 34.3% | 31.5% |
| V6 / V7 | 门控 / 规则 | 64 / 69 | 189 / 127 | 200 / 260 | 14.3% / 15.4% | 22.8% / 19.0% |

**结论**

1. **只看一个口径会被骗**：V1 幻觉率 19.4%，但拒答率 65.7%、答对 121 → 72；单靠提示只是拿拒答换幻觉。
2. **检索是唯一真正有效的一步**：配对幻觉 206 → 83、答对 138 → 249（均 p<0.001）；重排再加答对 +19（p=0.018，Holm 校正后 0.092，只算倾向）。
3. **误导题三种做法都没过判据**：V5 泛化挑错传染到正常题（配对幻觉 82 → 151）；V6 门控拦 19 误拒 67；V7 规则拦 14 误拒 7。
4. **迁移到 Qwen3-8B**（另一裁判，不可横比）：原样 67.9% → V4 29.5% → V8 窄题型提示 27.1%，属样本内结果。

**方法亮点**

- **裁判一致性**（取自已有记录，零新增调用）：跨裁判 188 条 κ = 0.78；同裁判重测 agnes κ = 0.68、gemini-flash κ = 0.99。
- **SQL 复现**：纯 SQL 重算报告表 1～3，与 Python 结果 521 项全部一致；另有 8 条窗口函数 / CTE 分析型查询。
- **自审**：外审后修正过度宣称，校正后不再显著的结论如实降级为倾向。

**局限**：单裁判、单次采样、只在开发集上；知识库是维基，SimpleQA 300 题里 258 题出处含维基，检索收益偏乐观；HalluQA 上裁判未独立核对；4B 与 8B 裁判不同。

**下一步**：留出集上确认 V4 / V8；两人独立标注 300 条做人工金标准；关键版本重复采样。
